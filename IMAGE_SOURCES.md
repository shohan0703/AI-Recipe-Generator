# ChefAI UI image sources

The bundled UI photographs are real food/cooking photographs collected from publicly accessible photography pages and stored locally in `assets/images/`. They are used only as static application imagery; ChefAI does not generate images.

- `hero_cooking.jpg` — Brittany Kelley Photography, culinary photography workspace: https://www.brittanykelleyphoto.com/services
- `biryani.jpg` — Uber Eats / Masala & Co food image: https://www.ubereats.com/fr-en/store/masala-%26co/xrsXzV__QfKVSHYVczWdGQ
- `combo_meal.jpg` — Pluckk combo meal image: https://pluckk.in/combo-meals-kook
- `ingredients.jpg` — Food52 ingredient photography: https://food52.com/story/21243-change-the-way-you-cook-blackening-technique

Please review the source site's current license/terms before redistributing the photos outside this university project.
